# arXiv Submission Checklist

## Pre-Submission

- [x] Title ve abstract hazır
- [x] Yazar bilgisi doğru
- [x] Kategoriler seçildi (cs.LG primary)
- [x] Cross-list kategoriler eklendi
- [x] Comments satırı yazıldı
- [x] Ana LaTeX dosyası arXiv-uyumlu (\today sabitlendi)
- [x] PDF derleme hatasız (0 hata)
- [x] Bibliyografi (21 atıf) tam
- [x] Şekil ve tablolar doğru
- [x] Matematik notasyon tutarlı

## Submission Steps (arXiv)

1. [ ] arxiv.org/login (veya hesap aç)
2. [ ] "Start New Submission" tıkla
3. [ ] License seç (CC-BY-4.0 önerilir)
4. [ ] Primary category: cs.LG seç
5. [ ] Cross-list: cs.CL, cs.AI, stat.ML ekle
6. [ ] Metadata doldur (METADATA.md'den kopyala)
7. [ ] Dosyaları yükle (main.tex, main.pdf)
8. [ ] arXiv'nin derlemesini bekle (~5 dk)
9. [ ] Preview'u kontrol et
10. [ ] Submit

## Post-Submission

- [ ] arXiv ID'yi not al (arXiv:2026.XXXXX)
- [ ] Preprint 1'in comments'ını güncelle (companion paper)
- [ ] GitHub README'ye arXiv linki ekle
- [ ] Hocalara arXiv linkini gönder

## Önemli Notlar

- arXiv **insan onayı** ister (24-48 saat ilk seferde)
- Türkçe supplement **isteğe bağlı** (ana makale İngilizce)
- Preprint 1'in arXiv ID'si belli olunca buraya ekle
