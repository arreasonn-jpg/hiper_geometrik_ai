# HGA Research Foundation

HGA is an experimental research platform for structured bilinear chains and
hash-addressed sparse memory. This site documents contracts that are testable,
reproducible, and deliberately narrower than general-intelligence or SOTA
claims.

## Start here

- Run the manifest-stamped foundation bundle with [`make reproduce`](REPRODUCE_ALL.md).
- Read the [CKPT-001 status](CKPT-001.md) for repository-complete work and
  external validation gates that code cannot complete.
- Read the [theory framework](THEORETICAL_FRAMEWORK.md) before interpreting
  Kronecker rank or capacity terminology.
- Consult the [API guide](api.md) for stable public Python and CLI entry points.

## Honest status

The project ships executable diagnostics, pinned benchmarks, Docker recipes and
CI definitions. It does not claim a published GHCR image, an independently
reviewed theorem, a peer-reviewed paper, broad multilingual pretraining, or a
validated scaling law unless an external record supplies that evidence.
